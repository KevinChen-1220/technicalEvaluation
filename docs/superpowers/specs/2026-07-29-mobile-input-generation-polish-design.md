# 移动端输入与生成体验优化设计

## 目标

修复 iPhone 底部安全区颜色断层和键盘遮挡输入框的问题，提高模型返回非标准 JSON 时的生成稳定性，移除示例试卷入口，并将生成加载状态整合到按钮内部。

## 安全区与键盘

使用 Expo 兼容的 `react-native-safe-area-context` 替代 React Native 核心 `SafeAreaView`。应用根视图覆盖完整屏幕，页面内容按顶部安全区增加内边距；底部 Tab 自身延伸到屏幕底部，并使用相同的白色背景填充底部安全区。页面滚动区域的底部留白同时计入 Tab 高度和安全区高度。

新增统一的屏幕滚动容器，组合 `KeyboardAvoidingView`、`ScrollView` 的自动键盘 inset、交互式收起和点击穿透设置。测评、设置、答题、结果和解析页面全部通过该容器呈现，确保低位输入框在 iOS 和 Android 键盘弹出后仍可滚动到可见位置。

## 生成结果稳定性

当前解析器只截取首尾花括号后调用一次 `JSON.parse`，无法处理模型常见的尾逗号、单引号、注释、代码围栏或轻微截断。引入 ISC 许可的 `jsonrepair`，保留严格解析为首选路径，仅在严格解析失败时修复候选 JSON 并再次解析。

若修复后仍无法解析，或解析成功但测评结构校验失败，生成流程自动重新请求一次完整试卷。第二次请求附带简短的失败原因并要求从头输出完整 JSON，不复用或拼接第一次的残缺内容。网络错误、鉴权错误和 HTML/XML 端点错误不自动重试，避免掩盖配置问题或重复无效请求。两次均失败时显示现有本地化错误。

## 示例试卷

移除首页“使用示例试卷”按钮、相关文案和运行时导入。应用启动时不再预置试卷，只有模型生成成功或打开历史记录后才设置当前试卷。测试仍可保留示例数据作为 fixture，但不会打包为用户功能入口。

## 按钮加载动画

生成按钮在加载时保持原尺寸和主色背景，内部显示“生成中”与三个依次上浮、淡入淡出的圆点，形成连续波浪节奏。动画使用 React Native `Animated` 和原生驱动，不引入维护状态不明的第三方加载按钮库；禁用点击但不降低到难以辨识的透明度。按钮外不再显示独立加载指示器。

## 验证

- 单元测试覆盖 JSON 修复、可重试与不可重试错误、最多两次请求以及示例入口移除后的状态行为。
- 类型检查和 Web 构建确认新增原生依赖与 Web 平台兼容。
- 使用 iPhone 尺寸视口验证底部 Tab 背景连续、按钮加载布局稳定、示例入口消失。
- 原生项目通过 Expo Doctor；完整测试、资源和 Web 元数据校验保持通过。
