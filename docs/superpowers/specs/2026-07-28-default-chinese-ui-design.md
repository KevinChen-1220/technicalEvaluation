# 默认中文界面设计

## 目标

SkillScope 的应用界面默认完整使用简体中文，避免只有输入框默认值为中文、其余界面仍为英文的割裂体验。题目生成语言继续由用户输入的测评主题决定，不因界面语言而锁定为中文。

## 语言边界

- 应用框架文案固定为简体中文，包括导航、标题、按钮、提示、空状态、状态标签、日期、难度和错误提示。
- 产品名 `SkillScope`、`API`、`Base URL` 等必要品牌或技术术语保留。
- 模型生成的题目、选项、解析、知识点和结果总结保持原始语言；中文主题生成中文，英文主题生成英文。
- 历史记录中的既有生成内容不迁移，只把承载它们的界面翻译成中文。

## 实现方案

新增轻量级 `zhCN` 文案模块，集中管理静态文案和难度、进度、日期、状态、已知错误的展示转换。当前不引入第三方国际化依赖，也不增加语言切换入口。

`App.tsx` 只负责组合页面和动态数据，不再散落英文界面文案。领域层继续保留稳定的内部错误和数据协议，由展示层在呈现时转换为中文，避免影响生成解析、数据库和既有测试契约。

示例试卷整体改为中文，使首次体验与默认中文界面一致。Web 文档的语言、标题、描述、Manifest 和无脚本提示也同步为中文。

## 验证

- 单元测试覆盖文案、难度、进度、日期、状态和错误转换。
- 示例试卷测试确认主要用户内容为中文。
- 完整运行 Jest、TypeScript、Web 构建和元数据校验。
- 在移动端视口检查测评、历史、设置、答题和结果页面，确认没有遗留英文界面文案或布局溢出。
