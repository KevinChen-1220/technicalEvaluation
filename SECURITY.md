# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues,
discussions, or pull requests. Report them through this repository's private
[Security Advisories](../../security/advisories/new) flow instead.

Include a clear description of the issue, affected versions or environments,
steps to reproduce it, and any suggested mitigation. Do not include API keys,
tokens, or other secrets in the report.

We will acknowledge receipt, investigate the report, and coordinate a fix and
disclosure where appropriate.
